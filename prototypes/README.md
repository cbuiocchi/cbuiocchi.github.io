# Prototypes

Small projects and prototypes, each in its own folder:

```
prototypes/
  my-prototype/
    index.html    Entry point. Served at https://cbuiocchi.github.io/prototypes/my-prototype/
    ...           Any other files the project needs (css, js, img, builds).
```

Each folder is self-contained, so use relative paths (`css/style.css`, not `/css/style.css`) to keep the project working on its own and away from the main site's files.
